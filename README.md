# Чайный таймер

Таймер для заваривания китайского чая методом проливов. У каждого чая своя кривая
времени (25с → 45с → 1:00 → 1:15…) — приложение хранит эти кривые и даёт заваривать
«по режиму», вместо того чтобы держать их в голове и в стороннем секундомере.

PWA: устанавливается на телефон и на ПК, полностью работает офлайн. Записи хранятся
локально и синхронизируются с вашим приватным GitHub-репозиторием в виде
`.md`-файлов, которые читаются в Obsidian.

## Что умеет

- **Режимы по чаям.** Название, картинка, заметки и один или несколько пресетов по
  объёму посуды: 150 мл → 8 г, 200 мл → 10 г. Проливы задаются отдельно для каждого
  объёма, потому что на разной посуде кривая времени может отличаться; если она
  совпадает — есть «скопировать проливы».
- **Температура — одна на пресет**, а не на каждый пролив: воду выставляют один раз,
  дальше она сама остывает. У пролива остаётся время плюс необязательная метка.
  Промывку можно отметить флагом — она не считается проливом при нумерации, так что
  шаг после неё это «Пролив 1».
- **Таймер с ручным старом каждого пролива.** Авто-перехода нет намеренно: между
  проливами вы физически переливаете чай, и момент старта должен быть ваш. Сверху
  всегда видно «150 мл · 8 г», чтобы отмерить лист до начала.
- **Сигнал** звуком и вибрацией, экран не гаснет пока идёт пролив. Сигнал повторяется,
  пока его не отключить кнопкой «Отключить сигнал» (или пробелом, или любым другим
  действием таймера) — конец пролива легко пропустить, когда телефон лежит рядом
  экраном вниз. Отсчёт идёт по абсолютному времени, поэтому уход вкладки в фон его
  не ломает.
- **Синхронизация** с приватным репозиторием: push при сохранении, pull по кнопке.
  Работает офлайн — несохранённое встаёт в очередь и уходит при появлении сети.
- **Тёмная тема** (системная, с переключателем).

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173/tea-timer/
```

Приложением можно пользоваться сразу, без GitHub и без токена — синхронизация это
бэкап, а не условие работы.

Чтобы настроить синхронизацию и деплой — **[docs/setup.md](docs/setup.md)**: создать
приватный репозиторий, выпустить fine-grained PAT с правом `Contents: Read and write`
на один репозиторий, включить Pages.

## Формат файла

Один чай = один файл. Frontmatter несёт полную структуру, таблицы под ним
генерируются для чтения глазами:

```markdown
---
id: 6f1c2a3b-1111-4222-8333-444455556666
title: Шу Пуэр «Лао Ча Тоу» 2018
updatedAt: 2026-07-26T10:00:00.000Z
presets:
  - id: aaaaaaaa-1111-4222-8333-444455556666
    vesselVolume: 150
    leafGrams: 8
    tempC: 95
    steps:
      - { seconds: 10, label: быстрая промывка, rinse: true }
      - { seconds: 25 }
      - { seconds: 45 }
---

# Шу Пуэр «Лао Ча Тоу» 2018

## 150 мл · 8 г · 95°

| Пролив   | Время | Метка            |
|----------|-------|------------------|
| промывка | 0:10  | быстрая промывка |
| 1        | 0:25  | —                |
| 2        | 0:45  | —                |
```

**Правите файл руками в Obsidian — правьте frontmatter.** Таблицы обратно не
парсятся и перегенерируются при следующей отправке.

## Стек

React 19 · Vite 8 · Tailwind v4 · shadcn/ui · IndexedDB (`idb`) · `vite-plugin-pwa`
· GitHub REST Contents API · GitHub Pages. Без бэкенда.

## Разработка

```bash
npm run verify   # линт + тесты + сборка (то же, что в CI)
npm test         # vitest
npm run smoke    # e2e в headless Chromium по собранной версии
```

Покрыто тестами ровно то, где бага была бы молчаливой и разрушила данные:
round-trip markdown с golden-снапшотом файла, движок таймера со скачками часов,
транслитерация и base64, клиент GitHub и оркестрация синхронизации.

## Ограничение на iOS

Заблокированный экран усыпляет веб-приложение целиком — JavaScript не исполняется, и
сигнала в конце пролива не будет. При возврате таймер покажет верное состояние, но
звук уже не прозвучит. Держите экран включённым; на экране заваривания на iOS об этом
есть напоминание. Вибрации в iOS Safari нет вообще.
